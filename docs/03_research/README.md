# Research level

Prerequisites: graduate analysis and PDE, the [graduate docs](../02_graduate/).

This level maps the frontier: the candidate proof architectures, the obstructions each faces, and the numbered research directions that the program pursues.

## Contents

- [`overview.md`](overview.md): the state of the art across the five architectures, written as a research orientation.
- [`research_directions/`](research_directions/): five numbered direction specs, each an attackable piece of the supercriticality gap with success criteria and the controls it must pass.
- [`reading_notes/`](reading_notes/): notes on the key reference sources (Fefferman's problem statement, Leray, CKN, BKM, ESS, Koch-Tataru, Tao, Buckmaster-Vicol, the textbooks).

## The spine

Everything is organized around the supercriticality gap (see [`../02_graduate/scaling_and_supercriticality.md`](../02_graduate/scaling_and_supercriticality.md)). The only all-time a priori bound is supercritical; every regularity criterion is critical; a proof must supply genuinely critical control. The directions are different attacks on supplying it, and each is checked against the three controls (2D smoothness, the criticality bookkeeper, the viscosity/Burgers control).

See [`../research_atlas/README.md`](../research_atlas/README.md) for the comprehensive catalog of all approaches and their obstructions, and [`../solutions/README.md`](../solutions/README.md) for the architecture-by-architecture summary.
