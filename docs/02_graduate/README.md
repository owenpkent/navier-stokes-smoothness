# Graduate level

Prerequisites: real and functional analysis, Sobolev spaces, a graduate PDE course.

- [`scaling_and_supercriticality.md`](scaling_and_supercriticality.md): the scaling symmetry, the precise notion of sub/critical/super, why the energy estimate is supercritical, and what that rules out.
- [`regularity_criteria.md`](regularity_criteria.md): weak solutions (Leray-Hopf), partial regularity (Caffarelli-Kohn-Nirenberg), and the conditional regularity criteria (Prodi-Serrin-Ladyzhenskaya, Beale-Kato-Majda, Escauriaza-Seregin-Sverak), each placed on the criticality scale.
